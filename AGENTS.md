# Правила проекта «Детский клуб Эврика»

## Тестирование и браузер

- **Запрещено использовать встроенный браузер и browser_subagent** для автоматической проверки сайта, если пользователь явно не попросит об этом в сообщении.
- Пользователь проверяет всю визуальную часть, адаптивность, навигацию и поведение интерфейса **самостоятельно в своём браузере**.
- Не запускать автотесты через браузер без прямой команды пользователя.
